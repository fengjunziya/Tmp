录屏演示命令（在同一个 PowerShell 窗口中分段执行）

当前只准备了提示词及命令，没有提前执行 Agent，也没有提前生成本次录屏的文本或视频。
两个项目 Agent 均使用 deepseek-flash / high、DeepSeek 官方 Responses API，只读取 DEEPSEEK_API_KEY。
录屏前确保当前 PowerShell 已设置 DEEPSEEK_API_KEY；不要在录屏中输入或展示真实密钥。项目不会自动加载 .env。
本机 python 已有 openai / pydantic 依赖，FFmpeg、ffprobe 和现有演示素材均可直接使用。

一、准备（每次重新录制都重新执行，生成新的日志目录）

Set-Location D:\Tmp
$env:PYTHONUTF8 = '1'
if ([string]::IsNullOrWhiteSpace($env:DEEPSEEK_API_KEY)) { throw 'Please set DEEPSEEK_API_KEY before recording.' }
$demoRun = 'D:\Tmp\runs\recording_' + (Get-Date -Format 'yyyyMMdd_HHmmss_fff')

二、Coding Agent：展示提示词，再让模型创建工作目录下的 .txt 文件

Get-Content -LiteralPath D:\Tmp\demo_recording\coding_prompt.txt -Encoding UTF8
python coding_agent.py run --task demo_recording/coding_prompt.txt --workspace D:/Tmp --run-dir "$demoRun\coding" --config config.example.json --acceptance demo_recording/coding_acceptance.json --allow-write coding_agent_demo.txt --max-turns 8 --total-timeout-s 300
if ($LASTEXITCODE -ne 0) { throw 'Coding Agent failed; inspect its result and logs before continuing.' }
Get-Content -LiteralPath D:\Tmp\coding_agent_demo.txt -Encoding UTF8

预期：模型通过 write_file 创建文件，finish 返回通过，终端显示 CODING_DEMO_OK 和 ok: true。
提示词不会预先创建目标文件；配套 JSON 是 Coding Agent 必需的完成检查，仅检查该文件及内容。
如果重复录制时文件已存在，可在录屏前手动将其另存为其他名称，让镜头再次展示新建过程。

三、Video Agent：使用现有 10 秒合成素材生成第一版

Get-Content -LiteralPath D:\Tmp\examples\request_v1.txt -Encoding UTF8
python video_agent.py create --assets materials/demo --request examples/request_v1.txt --run-dir "$demoRun\video" --config config.example.json
if ($LASTEXITCODE -ne 0) { throw 'Video Agent v1 failed; do not run the revision yet.' }
Write-Host "V1 exported: $demoRun\video\output_v1.mp4"
Invoke-Item -LiteralPath "$demoRun\video\output_v1.mp4"

第一版：动态视频在前、静态图片在后；标题“十秒灵感”。总时长 10 秒，带字幕、BGM 和 500ms 交叉溶解。
素材目录：D:\Tmp\materials\demo，包含 source_10s.mp4、still.png、bgm.wav。

四、Video Agent：追加修改要求，生成第二版

Get-Content -LiteralPath D:\Tmp\examples\request_v2.txt -Encoding UTF8
python video_agent.py revise --run-dir "$demoRun\video" --base-revision 1 --request examples/request_v2.txt --config config.example.json
if ($LASTEXITCODE -ne 0) { throw 'Video Agent v2 failed; inspect its logs.' }
Write-Host "V2 exported: $demoRun\video\output_v2.mp4"
Invoke-Item -LiteralPath "$demoRun\video\output_v2.mp4"

第二版：静态图片改到开头、动态视频放到后面；标题替换为“让灵感再快一步”。其他要求继承第一版。两版成片分别保留。
create 和 revise 必须使用同一个 $demoRun\video。每次正式重录使用全新目录，以便真正调用模型并重新导出。
Video Agent 在运行中主要写日志，终端暂时没有新文字属于正常情况；成功后会显示上述 V1/V2 exported 消息。

五、展示追加修改记录、验证结果和日志目录（可选）

Get-Content -LiteralPath "$demoRun\video\revision_diff.json" -Encoding UTF8
Get-Content -LiteralPath "$demoRun\video\validation_v1.json" -Encoding UTF8
Get-Content -LiteralPath "$demoRun\video\validation_v2.json" -Encoding UTF8
Invoke-Item -LiteralPath $demoRun

运行日志：$demoRun\coding 和 $demoRun\video；包括真实模型调用事件、工具调用、用量、时间线及视频验证结果。
无需额外执行全套测试，也无需重新生成素材。
